# 数据集（问数）使用说明

"数据集"用来上传 Excel / CSV 表格，然后直接用中文提问："9 月各渠道的成交金额是多少？""哪个地区达成率最低？"。
系统会把问题翻译成 SQL 去查询数据，给出结论、图表、结果表，SQL 也可以查看。

> 数据集和"文档管理"是分开的：表格数据**不会**进入文档问答，表格里的备注文字只用来帮助理解数据口径。

## 1. 上传与导入

1. 左侧菜单 →「数据集」→「上传数据」，选择知识库和文件。
   - 支持 **xlsx / xls / csv**（csv 自动识别 UTF-8 / GBK 编码，以及逗号、分号、Tab 分隔）；
   - 单个文件 **≤ 50MB**，单表 **≤ 100 万行、≤ 200 列**；每个知识库最多 50 个数据集；
   - 加密的 Excel 需要先取消密码；隐藏的 sheet 和空 sheet 会自动跳过。
2. 系统先自动分析，然后打开**导入向导**，确认无误后再正式导入：
   - **块识别**：一个 sheet 里有多张表（中间隔着空行或空列）时会自动拆开。蓝色是数据块，黄色是备注，灰色是忽略。可以在画布上拖动框选区域，"新增为数据块"；也可以把识别错的块改为"忽略"。
   - **表头**：自动识别标题行和多行表头（多行表头合并为"成交_成交金额"这样的列名）。表头行不对时可以手动修改。
   - **合并单元格**：自动向下填充。**合计/小计行**会自动去掉，避免重复计算。
   - **交叉表**：形如"地区 × 1 月…12 月"的宽表，系统会提示转换为长表（地区 / 月份 / 销售额），右侧可以对比转换前后的效果。值列名会根据标题自动推断，可以修改，也可以关闭转换。
   - **列名和类型**：可以修改列名。日期、金额（含 ¥、千分位、"万"）、百分比都会自动识别。
3. 点「确认导入」，状态从"导入中"变为"可用"后就可以提问。导入失败时，列表里会显示原因（如"超过 100 万行上限""没有可导入的数据"）。
4. 更新数据：目前不支持追加，需要删除后重新上传。

## 2. 补充说明，让回答更准

点击数据集名称打开详情，可以编辑：
- **数据说明 / 表说明**：这份数据是什么、统计口径；
- **列描述、同义词**：例如列"消耗"的同义词填"花费,成本"，列"成交金额"填"GMV,销售额"。

这些信息会提供给大模型，是提高准确率最有效的办法。表格里识别出的备注（如"消耗为不含税金额"）也会显示在这里。

## 3. 提问

在「智能问答」页左侧选择**问答方式**：

| 方式 | 适用 |
|---|---|
| 自动（默认） | 系统自动判断走文档问答、数据问答，还是两者混合 |
| 文档 | 只查制度、手册等文档 |
| 数据 | 只查数据集；可以在下方限定一个或几个数据集 |
| 混合 | 既要数据又要制度，例如"9 月各渠道 ROI 是否达到营销制度规定的标准？" |

数据类回答包含：
- **结论**：1–3 句话，数字全部来自查询结果；
- **使用数据**：用了哪个数据集、哪张表。如果其他数据集也可能回答这个问题，提示框会变成橙色，点「改用 X」就会用同一个问题、指定该数据集重新查询；
- **假设**：系统对问题做的理解（如"9 月按 2026-09-01~09-30 计算"）；
- **图表 / 表格**：可以切换。页面最多展示 500 行；
- **查看 SQL**：方便核对口径；
- **导出 CSV**：服务端重新执行同一条查询，最多 1 万行，可以直接用 Excel 打开。

支持追问，例如先问"9 月各渠道的成交金额"，再问"再按地区拆一下"。

**提问技巧**：说清楚时间范围（"2026 年 9 月""9 月 1 日到 15 日"）、指标（"成交金额"而不是"钱"）和维度（"各渠道""按地区"）。有多份相似的数据时，在问题里写上数据集名，或者在左侧限定数据集。

## 4. 权限与安全

- 数据集归属于知识库：能查看该知识库的人才能提问、预览、导出；只有编辑者 / 管理员能上传、修改、删除。
- 问答历史中的分析结果只有提问人本人和管理员能导出。
- 查询全部是只读的：只允许单条 SELECT，禁止访问文件、网络和系统函数，单次查询超时 10 秒（导出 30 秒）。
- 发给大模型的内容只有：表结构、每列常见取值、每表 3 行样例、最多 50 行查询结果。表格中的文字一律当作数据处理，"忽略之前的指令"之类的内容不会生效。

## 5. 常见问题

- **答案不对？** 先看"使用数据"和"查看 SQL"：表用错了就点「改用」或者限定数据集；口径不对就去详情里补充列描述或同义词。
- **问题被当成文档问题了？** 把问答方式切到"数据"。
- **导入后行数比 Excel 少？** 合计 / 小计行和空行已经被去掉了，这是正常的。
- **xls 里的公式**：读取的是 Excel 保存时的计算结果。由程序生成、从未用 Excel 打开保存过的文件可能没有计算结果，请先用 Excel 打开并保存一次。
